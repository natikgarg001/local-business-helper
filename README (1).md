# Local Business Helper

AI-powered tool that connects tourists with small local businesses
(dhabas, artisans, guides, homestays) in Ambala, Kurukshetra and Mullana.

## Problem
Small local businesses are invisible online and often cannot write
listings in English. Tourists cannot find authentic, reliable local options.

## Features
- Tourist search in Hindi/English: AI picks the best-matching listings and explains why
- Business owner flow: describe your shop in your own language, AI generates
  an English + Hindi tourist-friendly listing with a visitor tip
- One-tap Call and WhatsApp buttons, category filters
- Fallback keyword search when AI is unavailable

## Tech
Single-file HTML/CSS/JavaScript, no build step. AI via Claude (sample API).
Listings saved in browser localStorage.

## Run
Open index.html in any browser. AI features work in the Claude-hosted
version (https://claude.ai/artifact/S1o6rcmUu3CvvFdngHYuqm); offline it falls back to keyword search.

## Note
The 8 starting listings are demo data, not real businesses.
